# Облачная версия MOEX Paper Lab

Код подготовлен для GitHub Actions. До размещения в GitHub и первого успешного запуска он не работает по расписанию.

## Что запускается

- Дневная OHLCV-история 38 акций и IMOEX с 01.10.2025 через официальный MOEX ISS.
- Часовые свечи за 28 календарных дней. Сегодняшние дневные и ещё не завершённые часовые свечи отбрасываются. Для часов предусмотрен буфер задержки 15 минут.
- Повторные запросы, полная пагинация до пустой страницы, проверка OHLC, недублирующихся дат и ошибок источника.
- Прогнозы на 1/3/5/10 следующих доступных будних дневных наблюдений. Фиксированная модель среднего логарифмического изменения и сравнение с неизменной ценой.
- Walk-forward: MAE, RMSE, sMAPE, точность направления и фактическое покрытие эмпирического интервала. Проверка использует только прошлое каждого прогнозного момента.
- Неизменяемые журналы новых утренних прогнозов и отдельных проверок их результатов. Изменение старых строк блокирует сохранение в облако.
- Markdown, JSON и HTML-отчёты. Расписание — каждые два часа, с 06:17 до 22:17 МСК по будням. Планировщик GitHub может задержать или пропустить запуск.

Это первая воспроизводимая модель, а не подтверждение точности 95%. Интервалы 95% не равны вероятности угадать цену. Система не проводит сделки и не переносит образцы учебного портфеля в исследовательский журнал.

## Размещение

1. Добавить файлы из этого пакета в существующий `moex-paper-lab`, в его основную ветку. Учебные файлы остаются совместимыми.
2. Открыть **Actions → MOEX cloud research → Run workflow**. Для ручного запуска workflow должен находиться в основной ветке.
3. Проверить зелёный результат и открыть **Summary**. Там появится полный отчёт.
4. После первого успешного запуска появится ветка `moex-data`. Открыть `cloud_reports/latest.md` в этой ветке — удобная постоянная страница отчёта на телефоне.

Если GitHub потребует разрешить Actions или запись `GITHUB_TOKEN`, это делается в **Settings → Actions → General** владельцем репозитория. Правила защищённой ветки `moex-data` не должны запрещать боту сохранение результатов. Для исходной ветки достаточно чтения. Внешние ключи, брокерский доступ и сторонние Python-пакеты не требуются.

Если репозиторий публичный, исследования и журналы в `moex-data` тоже публичны. В них только рыночные данные и модельные прогнозы. Индивидуальные реальные позиции, долги и данные брокера в код не включены.

Объём бесплатных минут зависит от аккаунта и типа репозитория. Перед платным использованием нужно проверить собственные настройки биллинга. Пакет не включает подключение платного тарифа.

В публичном репозитории GitHub может остановить расписание после 60 дней отсутствия активности. Часовой скрининг не работает по выходным и не заменяет проверку корпоративных событий. Праздничные даты автоматически проявляются отсутствием свечей; горизонты считаются по наблюдениям, а не по календарным дням.

## Локальная проверка

```bash
python3 -m unittest discover -s tests -p 'test_*.py' -v
python3 cloud_runner.py
```

Повторный расчёт по уже сохранённым данным без сети и без изменения журнала:

```bash
python3 cloud_runner.py --offline --output offline_reports
```

Данные и журналы хранятся на отдельной ветке, исходная ветка не засоряется результатами. Один и тот же прогноз не добавляется повторно. Дневной запуск не создаёт прогноз задним числом. Даже пустой или неполный ответ MOEX явно отмечается в отчёте. Если не загружена ни одна акция, workflow завершается ошибкой и не перезаписывает предыдущий облачный отчёт.

## Метод и ограничения

Модель `shrink-drift20-v1`: `last_close * exp(0.25 * mean(last_20_log_returns) * horizon)`. Коэффициент фиксирован до оценки и не оптимизирован по текущей истории. Старт исторической оценки — после 120 наблюдений. Интервалы оцениваются из доступных на каждом шаге прошлых ошибок. Все результаты с перекрывающимися горизонтами зависимы.

Текущая вселенная инструментов задана списком и не воспроизводит исторический состав рынка. Цены не скорректированы на дивиденды и корпоративные действия. Из-за этого модель ещё нельзя считать проверенной торговой стратегией. Прогнозы отсчитываются от последнего завершённого дня, поэтому дневной исследовательский снимок нельзя трактовать как прогноз из текущей внутридневной цены.

Часовой фильтр: движение ≥0,5% за последний завершённый час, объём ≥1,5 медианы того же часа минимум пяти прошлых дней, положительная относительная сила за 20 наблюдений к IMOEX и медианный дневной оборот ≥20 млн ₽. Это список наблюдения, без проверки новостей, TP/SL и виртуального исполнения.
